# T3 Code BizPulse plugin

Read-only reference plugin for BizPulse portfolio health, growth evidence, and CRM follow-ups. It invokes BizPulse's JSON-first `pulse growth review` workflow and keeps the startup scope in plugin settings. BizPulse remains the owner of its own credentials and state.

Requested access: project filesystem read for repository context, configured BizPulse network access, and project/thread UI panels. The plugin does not request T3 thread dispatch or filesystem write access.
